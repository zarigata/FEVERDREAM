Double Agent

Uma camada de infraestrutura local para agentes de IA.

Projeto interno que explora como agentes de IA podem solicitar contêineres temporários, máquinas virtuais e recursos de processamento de um servidor Linux e receber os artefatos produzidos.

Conheça a arquitetura ↗

AI agents · MCP · Infrastructure

  • Interface MCP planejada para descobrir recursos e solicitar tarefas.
  • Arquitetura para ambientes isolados, agendamento e entrega de artefatos.
  • Roteiro que inclui CPU, GPU, desktops e máquinas virtuais.

Estágio do projeto

No momento, reúne especificação do produto e prévia web multilíngue. O runtime e o instalador são planejados, sem versão de produção.
